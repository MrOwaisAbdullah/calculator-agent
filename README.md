# Calculator AI Agent

An intelligent mathematical agent implemented in Python that combines LLM reasoning with precision tool calling for complex multi-step calculations and numerical problem solving.

## ✨ Features
- **Accurate Math Execution**: Offloads math operations to deterministic Python functions instead of relying on token prediction.
- **Multi-Step Problem Solving**: Decomposes word problems into sequential formulas.

## 🛠️ Tech Stack
- **Language**: Python 3
- **Tooling**: `uv`
